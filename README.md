# Contact Manager (Sample-repo1)

A simple interactive contact management web app built with HTML, CSS, Bootstrap and vanilla JavaScript.

## Features ✅
- Add a contact (name, email, phone, notes)
- Edit a contact
- Delete a contact
- List and search contacts
- Data persisted to browser localStorage

## How to use 🔧
1. Open `d:\Web Technologies\Sample-repo1\contact-app\index.html` in your browser (double-click or use Live Server).
2. Click **Add Contact** to create a contact.
3. Use **Edit** / **Delete** buttons to manage contacts.

## Notes 💡
- No server required; everything runs in the browser.
- Data is stored in `localStorage`; clearing browser data will remove contacts.

Enjoy! 🎉
